# Elite Decor - Luxury Interior Design

Elite Decor is a premium interior design website built with Next.js, Framer Motion, and Tailwind CSS. It showcases high-end interior design services, a portfolio of projects, and a seamless client experience.

## ✨ Features

- **Premium Design**: Sophisticated champagne gold color palette and high-quality imagery.
- **Dynamic Animations**: Smooth scroll-triggered animations powered by Framer Motion.
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop devices.
- **Fast Performance**: Optimized page transitions and asset loading.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Roshan-RPN/Elite_decor.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🌐 Deployment

The site is optimized for deployment on **Vercel**. Simply connect your GitHub repository to Vercel for automatic deployments on every push.
